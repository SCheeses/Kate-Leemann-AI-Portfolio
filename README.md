# Kate Leemann - Applied AI Portfolio

## About Me

I am an Applied AI and Robotics student at Houston Community College with a professional background in genetics research. My interests center on computer vision, biological and laboratory applications of AI, reproducible experimentation, and responsible evaluation in high-consequence settings.

I use this portfolio to document my progression from pixel-level image processing to classical machine learning and neural-network image classification. For each completed project, I include my executed Jupyter notebook, documentation, dependencies, saved results, and accompanying report.

## Technical Skills

- Python and Jupyter/Google Colab
- NumPy, OpenCV, Pillow, and Matplotlib
- Scikit-learn support vector machines
- PyTorch neural networks and TorchVision data pipelines
- TensorFlow/Keras dataset utilities
- Image preprocessing, feature extraction, and augmentation concepts
- Model training, classification reports, confusion matrices, and error analysis
- Git, GitHub, technical writing, and reproducible project organization
- Responsible AI framing for laboratory and medical-image applications

## Reproducibility Notes

- I ran the notebooks before publication and retained their code outputs and visualizations.
- I do not store public datasets in this repository. In each project README, I identify the source and explain how I load it.
- I report the saved metrics from the included notebook runs and state limitations such as small validation sets beside the results.
- I credit adapted educational material in the relevant project documentation and notebook.
